# Pocket Signal V7

Мобильная веб-версия для Safari.

## Файлы
- index.html — интерфейс
- style.css — мобильный дизайн
- app.js — индикаторы, сканер, журнал и статистика

## Возможности
- EMA 9/21/50
- RSI 14
- MACD
- ADX
- Bollinger Bands
- поддержка/сопротивление
- свечное подтверждение
- Signal Score
- CALL / PUT / NO TRADE
- журнал OPEN/WIN/LOSS
- статистика по парам и Score
- CSV-экспорт
- локальное сохранение в Safari

## Источник данных
Twelve Data. Перед использованием проверь условия API и доступность нужных инструментов/лимитов.

## Важно
Приложение является аналитическим инструментом. Оно не отправляет сделки в Pocket Option автоматически.
